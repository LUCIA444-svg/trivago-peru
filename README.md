# trivago-peru

Proyecto académico de **Diseño de Negocios Digitales** (ISIL).
Página demostrativa inspirada en un metabuscador de alojamientos, enfocada en destinos del Perú.

## Qué hace
- Buscador con región, fechas de llegada y salida, y número de viajeros.
- Validación de datos con mensajes en español.
- Tarjetas de alojamiento **de ejemplo** con filtros (Todos, Económicos, Confort) y orden por precio.
- Diseño adaptable a computadora, tablet y celular.

## Aviso
Los nombres y precios son ejemplos de diseño. No son hoteles verificados ni disponibilidad real.

## Tecnologías
HTML, CSS y JavaScript (sin librerías). Las fotos vienen de Unsplash.
